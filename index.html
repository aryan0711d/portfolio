Unity Editor Tool - Open Source - Asset Store Preview

Unity
Optimizer Pro

A one-click performance optimization toolkit for Unity that analyzes scenes and applies intelligent fixes - light clustering, shadow balancing, GPU instancing, platform presets. Includes a visual heatmap in-scene. Under review for the Unity Asset Store.

The tool analyzes the active scene and identifies common performance bottlenecks such as excessive lighting, overlapping light ranges, heavy shadow usage, and inefficient rendering configurations. It provides a one-click workflow that applies intelligent optimizations while preserving the overall visual quality of the scene. A rule-based approach combined with a heuristic scoring model evaluates performance and estimates frame rate improvements.
